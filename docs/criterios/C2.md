## 2. Criterios

**C2-01 (alta) · Compilan con Style Dictionary.** `C2-tokens.json` compila con Style Dictionary 5.x (5.6.1 del plan §1.8) a `tokens.css` y al tema de Tailwind sin errores ni advertencias de referencias rotas; la configuración de compilación está versionada y declarada en el reporte.
- Verifica: `cd /home/deepsec/finanzas-hogar/docs/contratos && npx style-dictionary build --config <configuración declarada> ; echo $?` (instalar `style-dictionary` si falta y anotarlo en «Paquetes instalados» con la versión). Esperado: código 0, 0 errores, 0 referencias sin resolver; `npx style-dictionary --version` impreso en el reporte.
- Evidencia: `docs/estado/wf1/<agente>.md` §Verificación línea `C2-01` con salida y versión.

**C2-02 (alta) · Formato DTCG válido.** Cada token tiene `$value` y `$type` (heredado del grupo o propio) de los tipos DTCG correspondientes (`color`, `dimension`, `fontFamily`, `fontWeight`, `duration`, `cubicBezier`, `shadow`, `number`); las referencias `{grupo.token}` resuelven; los colores son hex sRGB o el formato de color que el agente declare y Style Dictionary acepte.
- Verifica: script `python3 -I` que recorre el JSON: 0 tokens sin `$value`, 0 sin tipo efectivo, 0 referencias sin destino; conteo de tokens por tipo.
- Evidencia: línea `C2-02` con los conteos.

**C2-03 (alta) · Cobertura de categorías del plan.** Existen tokens de: **colores por rol y escala** (marca y neutro tintado en 11 pasos 50–950; los 8 roles semánticos —ingreso, gasto, ahorro, deuda/crédito, advertencia, error, éxito, información— y el rol de acción crítica; paleta categórica de personas y tiendas; paleta de 8 series de gráficas), **tipografía** (familia, escala 12/14/16/20/24/32, pesos, cifras tabulares), **espaciado** (4, 8, 12, 16, 24, 32, 48), **radios** (6, 10, 14), **sombras** (2 niveles en claro; bordes en oscuro), **movimiento** (150–250 ms, curvas estándar y enfática) y **puntos de quiebre** (360, 412, 768, 1024, 1440). Colores definidos en **claro y oscuro**.
- Verifica: lista de comprobación de las 8 categorías con conteo de tokens; script que verifica que cada token de color existe en los dos temas (0 faltantes).
- Evidencia: línea `C2-03` con la tabla categoría → conteo.

**C2-04 (alta) · C2 = DESIGN.md.** Todo token mencionado en `docs/design/DESIGN.md` existe en `C2-tokens.json` y todo color de las tablas de DESIGN.md (escalas, roles, categóricos, series) coincide con el valor del token (0 diferencias); la tabla de contraste de U2 cita nombres de tokens y sus valores son los de C2.
- Verifica: script `python3 -I` que extrae los hex de `DESIGN.md` y los compara con los valores de `C2-tokens.json` por nombre; esperado 0 diferencias y 0 tokens citados inexistentes.
- Evidencia: línea `C2-04`.

**C2-05 (alta) · Contraste calculado desde C2.** El script de contraste de U2 (U2-04) lee `C2-tokens.json` como única fuente y reporta **0 pares bajo umbral** (texto ≥ 4.5:1; texto grande y UI ≥ 3:1) en claro y oscuro para los pares semánticos definidos (texto/fondo, texto secundario/fondo, borde de campo/fondo, botón primario relleno/texto, roles/fondo, series/fondo de gráfica). Hay tokens semánticos de par (p. ej. texto sobre superficie) para que los componentes no combinen colores a mano.

**C2-06 (alta) · `tokens.css` utilizable.** `tokens.css` define variables `--color-*`, `--space-*`, `--radius-*`, `--shadow-*`, `--duration-*`, `--font-*` (o los prefijos que el agente declare, uno por categoría); el tema claro es el predeterminado, el oscuro se activa con `@media (prefers-color-scheme: dark)` **y** con un atributo explícito en el elemento raíz (interruptor de tema), y toda variable de color está definida en ambos; `prefers-reduced-motion` reduce o anula las duraciones no esenciales.

## 3. No aceptable
- Tokens que no compilan o compilan con advertencias de referencias rotas; JSON que no sigue DTCG.
- Colores definidos solo en un tema; tema oscuro sin interruptor manual; colores sueltos en CSS fuera de los tokens.
- Diferencias entre DESIGN.md y C2; contraste calculado sobre valores que no son los de C2.
- Fuentes o iconos desde terceros; archivos de fuente ausentes.
- Tokens inventados que no usa ningún componente; duplicados sin alias.
- Valores de color distintos de los aprobados (matiz 280°) sin bloqueo.
- Salidas generadas a mano que no coinciden con las compiladas.

## 4. Umbrales numéricos (del plan)
- 0 pares bajo umbral: texto ≥ 4.5:1, UI y texto grande ≥ 3:1 (C2-05).
- Escalas de 11 pasos (50–950) para marca y neutro (C2-03).
- 8 roles semánticos + acción crítica; 8 series de gráfica; 8 entradas categóricas (personas y tiendas) (C2-03).
- Espaciado 4/8/12/16/24/32/48; radios 6/10/14; tipografía 12/14/16/20/24/32; movimiento 150–250 ms; quiebres 360/412/768/1024/1440 (C2-03).
- Style Dictionary 5.x, Tailwind 4 (C2-01, C2-07).

Botón con etiqueta en infinitivo y, si ayuda, un icono de 20 px a la izquierda; un solo primario visible por pantalla.

- **Cuándo:** primario para la acción principal de la pantalla, hoja o diálogo («Registrar gasto»); secundario para apoyo («Cambiar semana»); de texto para «Cancelar» o «Mostrar 3 más»; destructivo solo en el diálogo que confirma o en «⋯» («Borrar gasto»); acción crítica solo dentro de su diálogo, con verbo y cantidad («Borrar 12 gastos»).
- **Provee quien lo usa:** `<button>` nativo (o `<a>` si navega), la etiqueta, el icono opcional, `aria-label` si es de solo icono, y la razón en texto cuando está deshabilitado (`aria-disabled="true"` + `aria-describedby`).
- **Hacer:** alto `var(--size-control-coarse)` con puntero grueso y `var(--size-control-fine)` con fino; `var(--size-control-primary-sheet)` para el primario de una hoja; relleno `var(--space-3)`; `var(--space-2)` entre botones. Ocupado: `loader-circle` en lugar del icono, la etiqueta se queda y `aria-busy="true"`.
- **No hacer:** dos primarios a la vista; texto blanco sobre marca 600; esconder un botón que no se puede usar; poner el atajo dentro del botón.
- **Tokens:** `var(--ui-action-primary-bg)` y sus `-hover`/`-pressed`, `var(--ui-text-on-primary)`, `var(--ui-border-control)`, `var(--ui-border-control-hover)`, `var(--ui-surface-hover)`, `var(--ui-surface-pressed)`, `var(--ui-action-destructive-bg)`, `var(--ui-text-on-destructive)`, `var(--ui-action-critical-bg)`, `var(--ui-text-on-critical)`, `var(--ui-surface-disabled)`, `var(--ui-text-disabled)`, `var(--ui-border-focus)`, `var(--radius-sm)`.
